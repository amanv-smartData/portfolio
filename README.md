# Portfolio — Aman Verma

My personal portfolio website. A single-page site built with plain HTML and CSS — no frameworks, no build step.

🔗 **Live site:** https://amanv-smartData.github.io/portfolio/

---

## About

I'm a LAMP stack developer with 3+ years of experience building web applications with Laravel, PHP and MySQL. This site lists what I work with, the projects I've shipped, and how to reach me.

## Features

- Single HTML file, no dependencies or build tools
- Responsive layout — works on mobile, tablet and desktop
- Automatic light and dark mode based on system settings
- Hand-drawn SVG diagram of the LAMP stack
- Keyboard-accessible navigation and reduced-motion support
- Loads fast — only web fonts are fetched externally

## Run it locally

```bash
git clone https://github.com/YOUR_USERNAME/portfolio.git
cd portfolio
```

Then open `index.html` in your browser. That's it — there's nothing to install.

## Deploy on GitHub Pages

1. Push this repo to GitHub.
2. Go to **Settings → Pages**.
3. Under **Source**, pick the `main` branch and the `/root` folder.
4. Save. Your site goes live at `https://YOUR_USERNAME.github.io/portfolio/`.

## Make it yours

Everything lives in one file, so edits are easy:

- **Colors** — change the custom properties in the `:root` block at the top of the `<style>` tag. Dark mode values are in the block below it.
- **Content** — edit the text directly in the HTML. Sections are marked with comments.
- **Links** — replace `YOUR_USERNAME` and `YOUR_LINKEDIN` with your own handles.
